An original open-world action game built for the Make GTA 6 bounty on make.fun.

## Features
- Open-world city exploration
- Vehicle driving and traffic
- Police pursuit and wanted levels
- Missions, combat, and weapons
- HUD, minimap, and saved progress
- Procedural audio
